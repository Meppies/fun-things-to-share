# NS Reisadvies — verhuisd

Deze integratie woont vanaf v1.3.0 in een eigen repo zodat hij via HACS
geïnstalleerd kan worden:

**Nieuwe locatie:** <https://github.com/Meppies/ha-ns-reisadvies>

## Wat staat daar

- HACS-compatibele Home Assistant integratie (`custom_components/ns_reisadvies/`).
- Companion Lovelace-kaart, auto-geregistreerd.
- Releases met changelog, CI op Hassfest + HACS.

## Installeren

HACS → Integrations → ⋮ → *Custom repositories* → URL
`https://github.com/Meppies/ha-ns-reisadvies`, category **Integration** →
*Download* → Home Assistant herstarten.
